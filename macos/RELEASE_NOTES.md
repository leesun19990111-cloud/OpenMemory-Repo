macOS 13 이상에서 사용하는 OpenMemory 첫 미리보기입니다. Apple Silicon과 Intel을 함께 지원하는 Universal 앱입니다.

- Windows판과 같은 파란색 겹친 창 아이콘과 작업 목록 디자인
- 메뉴 막대 상주, 현재 작업 저장·기록 초기화·저장된 작업 열기
- 앱이 공개한 문서 경로와 Finder 폴더 수집, 구분 가능한 창 위치·크기·최소화 상태 복원
- 선택 행 제외와 로그인 시 자동 복원
- 설치마법사 PKG와 Applications로 옮기는 DMG 제공

설치 후 손쉬운 사용 권한을 허용해야 창을 읽고 이동할 수 있습니다. Finder 폴더를 수집하려면 Finder 자동화 권한도 필요합니다. 문서 경로가 공개되지 않는 앱은 제목을 보관하고 앱만 실행합니다. 내부 탭·도킹 패널·Spaces 배치는 완전히 복원하지 않습니다.

GitHub macOS 환경에서 단위 검사, Apple Silicon·Intel 컴파일, Universal 확인, 실제 앱 실행과 화면 렌더링을 수행했습니다. 사용자의 Mac에서 권한을 허용한 Office·Adobe·Finder 복원과 실제 재부팅은 별도로 확인해야 합니다. Revit은 Windows 가상환경에서 Windows판을 사용해야 합니다.
