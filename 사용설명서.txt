OpenMemory 2.3.0 — 프로그램·문서·폴더와 창 배치 복원

설치 및 업데이트
  OpenMemory-Setup-2.3.0-x64.exe를 실행하고 한국어 설치마법사를 따르세요.
  Windows 10/11 64비트, .NET Framework 4.8 이상이 필요합니다.
  현재 사용자 계정의 %LOCALAPPDATA%\Programs\OpenMemory에 설치됩니다.
  기존 OpenMemory는 트레이에서 [OpenMemory 종료]를 선택한 뒤 업데이트하세요.
  업무 프로그램은 별도로 설치되어 있어야 합니다.
  Revit 연결은 기본 설치에 포함됩니다. Revit을 다음에 재시작하면 적용됩니다.
  지원하는 Revit 연결: 2021 / 2023 / 2024 / 2026 / 2027.
  Adobe 연결은 호환성 확인이 필요한 선택 기능입니다.
  자동 복원이 필요하면 설치 화면에서 Windows 로그인 시 자동 열기를 선택하세요.
  이전 휴대용 버전 사용자는 새 앱에서 자동 시작 체크를 껐다 켜 새 경로를 등록하세요.
  이 설치 파일에는 공인 Windows 코드 서명이 없습니다.

처음 사용할 때
  1. 업무 프로그램의 문서 수정 내용을 먼저 저장합니다.
  2. 원하는 창 위치·크기를 정한 뒤 [현재 작업 저장]을 누릅니다.
  3. 목록의 복원 범위를 확인합니다. 연결된 문서는 별도 문서 행에 표시됩니다.
  4. 다음에 [저장된 파일 열기]를 누르면 작업을 연 뒤 창 배치를 적용합니다.
  기존 저장 기록에는 창 배치가 없으므로 업데이트 후 한 번 새로 저장하세요.

창 배치
  각 최상위 창의 위치·크기·최대화·최소화 상태를 함께 기록합니다.
  같은 프로그램의 여러 창은 제목으로, 탐색기는 폴더 경로로 구분합니다.
  파일이 늦게 열리는 경우 창 감지를 약 45초 기다립니다.
  실제 위치 적용을 확인한 개수와 찾지 못한 창을 복원 결과에 표시합니다.
  창을 구분할 수 없거나 앱이 위치 변경을 거부하면 결과에 표시합니다.
  모니터 구성이나 작업 영역이 바뀌면 현재 화면 안으로 위치·크기를 조정합니다.
  DPI·해상도 변경이나 앱 자체 최소 크기에 따라 픽셀 크기가 달라질 수 있습니다.
  앱 내부 탭 순서·도킹 패널·편집 화면·활성 문서·창 겹침 순서는 복원하지 않습니다.
  탐색기 전체 탭 구성도 복원하지 않습니다. 각 앱 내부 탭은 별도 창이 아닙니다.

트레이 상주와 우클릭 메뉴
  창의 X를 눌러도 종료되지 않고 Windows 시계 옆 알림영역에 상주합니다.
  숨겨진 아이콘(^) 안에 배치되는지는 Windows 설정에 따릅니다.
  현재 작업 저장: 열린 프로그램·폴더·감지 가능한 문서와 창 배치를 새로 저장합니다.
  저장된 작업 초기화: 기록을 초기화합니다. 원본 업무 파일은 삭제하지 않습니다.
    이전 기록은 %LOCALAPPDATA%\OpenMemory\reset-backups에 보관합니다.
  저장된 파일 열기: 최신 기록의 작업을 실행순번대로 열고 창 배치를 적용합니다.
  컴퓨터 시작 시 열기: 체크하면 Windows 로그인 약 15초 후 최신 기록을 자동 복원합니다.
    체크·해제를 눌러도 메뉴와 트레이 아이콘이 유지됩니다.
    NAS·VPN이 늦게 연결되면 연결 후 저장된 파일 열기를 다시 누르세요.
  아이콘 더블클릭 또는 목록 창 열기로 목록을 엽니다.
  완전히 종료하려면 OpenMemory 종료를 선택합니다.

목록 편집
  앞의 숫자는 실행순번입니다. 파랗게 선택된 행을 목록에서 제외할 수 있습니다.
  Ctrl·Shift로 여러 행을 선택할 수 있습니다. 제외 결과는 즉시 기록됩니다.
  모두 제외해도 현재 작업 저장을 누르면 현재 열린 작업을 새로 수집합니다.
  제외해도 실제 업무 파일이나 열린 창은 삭제·종료되지 않습니다.

프로그램별 문서 복원 범위
  Excel·PowerPoint: 열린 로컬·공유폴더 문서 감지와 파일 재열기.
  Word·AutoCAD·한글: 앱의 문서 연결을 통해 읽을 수 있는 경로를 기록합니다.
    앱 버전·권한·대화상자에 따라 감지가 제한될 수 있습니다.
  Revit: 연결이 작동하면 열린 모델 경로와 사용한 Revit 실행 경로를 기록합니다.
    설치 직후 이미 실행 중인 Revit은 다음에 다시 실행해야 연결됩니다.
    재시작 후 현재 작업 저장을 눌러 모델 문서 행이 생기는지 확인하세요.
    수동 추가 모델은 Revit 버전 지정이 필요합니다. 다른 버전으로 임의 변환하지 않습니다.
    클라우드 모델·미저장 문서 등 로컬 경로가 없는 모델은 제한됩니다.
  Adobe: Photoshop·Illustrator·InDesign COM과 선택 CEP 연결을 사용합니다.
    CEP는 Premiere Pro·After Effects 프로젝트도 조회하도록 구현되어 있습니다.
    이 PC에서 전체 Adobe 앱의 실제 문서 재열기는 검증하지 못했습니다.
    앱·버전에 따라 연결이 작동하지 않으면 프로그램만 실행합니다.
  Figma 데스크톱: 확인 가능한 제목 기록, 앱 실행 및 구분 가능한 창 배치 복원.
    파일 링크 자동 수집과 Figma 내부 문서 자동 복원은 지원하지 않습니다.
  브라우저: Chromium 계열은 마지막 종료 세션 복원을 요청합니다.
    저장 순간의 탭 목록 스냅샷은 아닙니다. 웹 Figma도 이 범위에 따릅니다.
  기타 프로그램: 확인 가능한 제목·실행 경로를 기록하고 앱을 실행합니다.
  문서 연결이 없으면 제목·확인된 경로는 보관하되 프로그램만 다시 실행합니다.
  '연결된 문서 N개 복원'의 실제 문서는 별도의 문서 행에서 확인하세요.

문서 내용과 보관
  OpenMemory는 원본 문서를 자동 저장·덮어쓰기·삭제하지 않습니다.
  미저장 수정 내용은 보관하지 않으므로 각 업무 앱에서 먼저 저장하세요.
  파일을 열 때 해당 앱의 자동 저장·매크로·버전 변환·동기화가 실행될 수 있습니다.
  원본 바이트 보존 검사는 임시 Excel·PowerPoint 문서로 수행했습니다.
  모든 앱의 모든 파일 형식에 대해 손상 가능성 0을 보장하는 것은 아닙니다.
  기록: %LOCALAPPDATA%\OpenMemory\sessions (문서 경로·창 제목 포함).
  다른 사람에게 배포할 때는 설치 파일만 전달하세요. 개인 기록은 포함되지 않습니다.
  Windows 설치된 앱에서 제거할 수 있으며 작업 기록과 원본 업무 파일은 유지됩니다.
