OpenMemory 2.3.0

프로그램·탐색기 폴더·감지 가능한 문서와 창의 위치·크기·최대화·최소화 상태를 기록하고 다시 엽니다.
업데이트 후 [현재 작업 저장]을 한 번 눌러야 새 창 배치 정보가 기록됩니다.

문서 경로가 감지된 경우에는 파일을 다시 엽니다.
문서 연결이 없으면 확인 가능한 창 제목을 보관하고 프로그램만 실행합니다.
앱 내부 탭·도킹 배치와 미저장 수정 내용은 복원하지 않습니다.
창을 구분할 수 없거나 앱이 위치 변경을 거부하면 복원 결과에 표시합니다.

Revit 연결은 기본 설치에 포함되며 Revit을 다음에 재시작하면 적용됩니다.
Adobe 문서 연결은 실제 앱·버전별 호환성 확인이 필요한 선택 기능입니다.
Figma 문서 링크 자동 수집은 지원하지 않습니다.
브라우저는 마지막 종료 세션 복원을 요청하며 저장 시점의 탭 스냅샷은 아닙니다.

설치 대상: Windows 10/11 64비트, .NET Framework 4.8 이상.
현재 사용자 계정에 설치됩니다. 업무 프로그램은 별도로 설치되어 있어야 합니다.
업데이트·제거 전에 OpenMemory 트레이 메뉴에서 종료하세요.
제거 시 저장한 작업 기록과 원본 업무 파일은 유지됩니다.
이 설치 파일에는 공인 Windows 코드 서명이 없습니다.
